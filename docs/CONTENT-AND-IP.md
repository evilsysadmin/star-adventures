# Content and intellectual-property boundary

The game is independently developed under ShadowOps. A personal Star Trek: TNG-inspired **private prototype** is an intended creative direction, but this GitHub repository is currently **public**.

Rules before changing repo visibility:
- No copied dialogue, episode scripts, artwork, music, models, logos or proprietary game assets.
- The example campaign and public-facing text must use original generic names.
- Documentary references to an inspiration are not themselves claims of an official affiliation.
- Franchise content must be kept separate from the engine and should not be introduced into this public history.

Private use or noncommercial distribution does not automatically grant IP permissions. Before any eventual public release, complete a rights audit and replace or license all protected names, designs and audiovisual content. Deleting files later does not remove them from git history: keep sensitive content out from the start.
